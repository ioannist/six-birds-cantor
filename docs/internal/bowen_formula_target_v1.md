# Bowen Formula Target v1

## Decision
- Outcome: `narrowed_and_proved`
- The primary class is narrowed to the subclass where lower-pressure packaging is exactly the depth-`n` cylinder family and cylinder geometry is disjoint enough that the packaged and cylinder sums coincide levelwise.

## Selected hypothesis
- Selected hypothesis family: `narrow_hybrid`
- Working proved class ID: `narrow_hybrid_affine_cylinder_class`

## Theorem statement
Let `K` be a set generated by a family in `narrow_hybrid_affine_cylinder_class`, meaning: finite-memory stationary admissibility, uniform contraction, bounded distortion / affine diameter control, usable separation, feedback-free admissibility, fixed lens/packaging, lower-pressure packaging admissible, exact cylinder packaging, and disjoint cylinder geometry.

For `s >= 0`, define
- `Z_n^U(s) = sum_{w in A_n} |K_w|^s`, where `A_n` is the admissible depth-`n` word set and `K_w` is the depth-`n` cylinder image;
- `P^U(s) = limsup_n (1/n) log Z_n^U(s)`;
- `Z_n^L(s)` from the lower-pressure packaged family at depth `n`;
- `P^L(s) = limsup_n (1/n) log Z_n^L(s)`.

On the proved class, `Z_n^L(s) = Z_n^U(s)` for every depth `n` and every `s`, so there is a single pressure
`P(s) := P^U(s) = P^L(s)`.
Let `s_*` be the unique zero of `P`. Then

`dim_H K = s_*`

where `P(s_*) = 0`.

## Proof route
1. Upper bound already available from T17: if `P^U(s) < 0`, then `dim_H K <= s`.
2. Lower bound already available from T18 on the lower-pressure packaging-admissible core subclass: if `P^L(s) > 0`, then `dim_H K >= s`.
3. New coincidence step: on `narrow_hybrid_affine_cylinder_class`, exact cylinder packaging plus disjoint cylinder geometry imply the lower packaged family at every depth is exactly the admissible cylinder family, with no multiplicity loss and no geometric coalescing. Therefore `Z_n^L(s) = Z_n^U(s)` for all `n,s`, hence `P^L = P^U = P`.
4. Final Bowen-formula conclusion: for `s > s_*`, `P(s) < 0`, so the T17 upper bound gives `dim_H K <= s`; for `s < s_*`, `P(s) > 0`, so the T18 lower bound gives `dim_H K >= s`. Letting `s` approach `s_*` from both sides yields `dim_H K = s_*`.

## Why the rejected hypothesis options are not the default right now

## Outside the proved class
Dropped from the primary class for this theorem:
- stage-dependent / nonstationary admissibility families;
- any family where lens or packaging feeds back into admissibility;
- local-domain families where packaged pieces are not exactly the depth-`n` cylinder family;
- families with overlap/coalescing that destroys cylinder-level equality of upper and lower sums.
