# Continuous Theorem Assumptions v1

## What is being extracted from the continuous regime
The continuous kernel pilot and regime sweep identify a reproducible lawful exploratory full-loop regime with all six primitives causally active, persistent kernel variation, rotating lens/packaging competition, and active budget/tau feedback.

## What is not yet being claimed as a theorem
This is not yet a theorem about dimension, pressure, or equilibrium. It is only the assumption pack and class freeze that a later theorem may use.

## Working theorem class
`continuous_full_loop_lawful_kernel_class`

## Stretch theorem class
`continuous_full_loop_lawful_kernel_class_with_wider_parameter_shell`

## Formal assumptions
The later theorem should assume:
- the substrate is a continuous operator state
- all six primitives are causally closed in one loop
- P1 rewrite is active
- P2 gating is active
- P3 timescale adaptation is active
- P4 lens competition is nondegenerate
- P5 packaging competition is nondegenerate
- P6 budget dynamics are active
- the kernel does not fast-collapse
- selection is stabilized by hysteresis rather than by freezing
- the lawful exploratory regime persists under a small parameter shell

## Empirical proxies for those assumptions
The pilot and sweep show:
- nontrivial variation in every run
- three-way lens and packaging switching
- active tau adaptation
- nontrivial budget range and volatility
- no near-frozen or collapsed sweep runs

## Primitive necessity assumptions
The knockout audit supports that every primitive matters. P5 is not observational: removing it collapses packaging switching and materially weakens the loop.

## Generated-object / theorem-object distinction
The generated object is the continuous full-loop kernel family and its regime shell. The theorem object is the class of such generated kernels satisfying the extracted assumptions, not the 600-step trajectory itself.

## What a later theorem should try to prove next
A later theorem should prove a lawfulness or thermodynamic statement for the continuous full-loop lawful kernel class, using the extracted assumptions rather than the raw simulation trace.
