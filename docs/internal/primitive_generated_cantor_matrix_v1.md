# Primitive-Generated Cantor Matrix v1

## What went wrong in the previous branch
- We treated the six primitives mostly as labels attached to preselected theorem families.
- That made the search family-first instead of substrate-first.
- P1 and P6 were reduced to diagnostics or thresholds, and P4/P5 were frozen too early.
- The result was a sequence of imported theorem classes, not a primitive-generated Cantor substrate.

## How PICA bootstraps lawful substrates
- In PICA, cells are active generators: each `actor <- informant` bundle writes state that feeds back into the next update.
- Lawfulness comes from repeated bundle interaction in bundle space, not from tagging a family after the fact.
- The point of the reset is to let a small cell bundle co-generate the substrate, the lenses, the packaging, and the audit ledger.

## Cantor analogue of the minimal substrate
- Base affine map pool: a small family of contracting interval maps on `[0, 1]`.
- Domain pool: core, waiting, return, and overflow windows.
- Optional internal phase/state: a small protocol variable that changes update order or lens preference.
- Lens choices: raw cylinders, overlap sectors, return-core partitions, package compactness.
- Packaging choices: singleton, overlap-sector, return-length, slope-cluster.
- Audit/budget ledger: an endogenous income ledger that can amplify successful branches.

## Cantor meanings of P1–P6 as active generators
- `P1`: affine/domain rewrite operator that changes branch parameters or splits a branch.
- `P2`: admissibility gating of branches and domains.
- `P3`: autonomous protocol/phase update on rule application.
- `P4`: competing lenses that choose how the current substrate is viewed.
- `P5`: competing packaging maps that coalesce cylinders or return blocks.
- `P6`: endogenous audit/budget/income, not diagnostic-only; it can amplify branches when the ledger is positive.

## Reduced cell bundle search space
- Structural baseline: `P2<-P4`, `P4<-P4`, `P5<-P4`.
- Structural competition: `P2<-P4`, `P2<-P5`, `P4<-P4`, `P5<-P4`.
- Budget-feedback: `P2<-P6`, `P5<-P6`, `P6<-P4`.
- Protocol-lens: `P3<-P4`, `P4<-P3`, `P3<-P3`.
- Rewrite bundle: `P1<-P3`, `P2<-P1`, `P4<-P3`, `P6<-P4`.
- Amplifying bundle: `P1<-P6`, `P2<-P6`, `P3<-P6`, `P4<-P6`, `P5<-P6`, `P6<-P6`.

## What counts as a lawful generated substrate
- A repeated bundle update reaches a stable attractor or near-attractor.
- The closure/idempotence defect is small on the frozen update window.
- The induced core is nontrivial, even if it remains finite-state-renewal-like.
- Return structure is richer than a single static package.
- The substrate is generated by actual multi-primitive interaction, not by constraint-only P2 logic.

## Decision rule for whether the six-birds reset is working
- Working means at least one bundle produces a stable, nontrivial generated substrate via multi-primitive interaction.
- If only static P2-style gating works, the reset has failed.
- If the bundle set is too small but the framework is right, that would justify expanding the bundle space rather than abandoning primitive generation.
