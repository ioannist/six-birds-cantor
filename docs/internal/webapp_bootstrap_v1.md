# Webapp Bootstrap v1

- Chosen stack: `React + TypeScript + Vite`
- Test stack: `Vitest + Testing Library`
- App path: `apps/cantor-web/`
- Expected data path: `apps/cantor-web/public/data/v1/`
- Root commands:
  - `make web-install`
  - `make web-dev`
  - `make web-build`
  - `make web-test`
- App posture: static, data-driven, no backend
- Browser scope rule: no theorem logic runs in the browser; later tickets should load frozen exported JSON only
