## Working thermodynamic target

## Stretch thermodynamic target

This has the highest Level-3 upside because it threads pressure through the induced packaging object, but it is a later and more delicate extraction.

## Why the rejected route is not the default now
`skew_product_path_pressure` is too close to a raw path statistic. It is useful as a reserve comparison, but it is not the best default if the goal is to keep the theorem object centered on the continuous operator cocycle rather than on a trajectory summary.
