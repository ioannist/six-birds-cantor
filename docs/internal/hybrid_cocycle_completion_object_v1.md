# Hybrid Cocycle + Completion Object v1

## Question being decided
Does the closed cocycle-pressure object plus the packaging completion endomap produce a broader theorem object than the cocycle route alone?

## Candidate hybrid stories
- `cocycle_final_best_story`
- `hybrid_same_class_stronger_object`
- `hybrid_with_forcing_broader_candidate`

## Closed cocycle theorem underneath
The closed cocycle route is the pressure theorem on `continuous_full_loop_lawful_kernel_class_shell_stable`. It is already closed and shell-stable.

## Completion object underneath
The packaging completion object is the fixed-point theory of `E_{tau,f}`. Its packaged objects are fixed points, with saturation and `P4<-P5` refinement already observed in the current diagnostics.

## Why the previous packaging question was too weak
Comparing packaging as an observable against the cocycle route asked about coverage of families. The paper-level question is object identity: whether completion fixed points define theorem objects that are richer than the cocycle object alone.

## Hybrid theorem object candidate
The candidate hybrid object is a cocycle theorem object whose packaged states are determined by the completion endomap. On current evidence this changes object identity, but not theorem-class breadth.

## Saturation and P4<-P5 forcing
Saturation is real and the packaging diagnostics record `P4<-P5` refinement events. Those events generate new packaged strata, but they do not yet force a broader theorem class beyond the closed cocycle route.

## Object-broadening tests
- Completion fixed points distinguish more object strata than the cocycle route alone.
- Saturation and `P4<-P5` refinement create nontrivial packaged strata.
- The class, however, still looks equivalent on current evidence.

## Decision
`hybrid_real_but_not_yet_broader`

The hybrid object is mathematically real and richer than the cocycle route alone, but it does not yet justify a broader theorem class.

## What the next theorem ticket should try to prove
A future theorem should prove whether the hybrid object actually widens the class, or whether the cocycle route remains the final best story and the completion object stays a same-class refinement.
