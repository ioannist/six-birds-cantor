# Bowen Formula Target v2

## Decision
- Outcome: `narrowed_and_proved`
- The theorem remains narrower than the T14 primary class, but it is enlarged beyond v1 by replacing the old disjoint-cylinder coincidence step with bounded-overlap coincidence on an equal-scale finite-memory prefix-memory subclass.

## Selected hypothesis
- Selected hypothesis family: `narrow_hybrid`
- Working proved class ID: `narrow_hybrid_bounded_overlap_affine_cylinder_class`

## What changed from v1
- T17 upper bound is reused unchanged.
- T18 lower route is reused on the same lower-pressure core.
- The old T19 coincidence step `Z_n^L = Z_n^U` on the disjoint subclass is replaced by the bounded-overlap coincidence theoremlet from S1-T2:
  `Z_n^L(s) <= Z_n^U(s) <= M Z_n^L(s)` with `M` independent of depth.
- This strictly enlarges the proved class to include `contextual_local.prefix_memory_last_digit_rule`.

## Theorem statement
Let `K` be generated by a family in `narrow_hybrid_bounded_overlap_affine_cylinder_class`, meaning: finite-memory stationary admissibility, uniform contraction, bounded distortion / affine diameter control, usable separation, feedback-free admissibility, fixed lens/packaging, lower-pressure packaging admissible, exact cylinder packaging, equal-scale cylinders at each depth, and bounded cylinder multiplicity independent of depth.

For `s >= 0`, define
- `Z_n^U(s) = sum_{w in A_n} |K_w|^s`, where `A_n` is the admissible depth-`n` word set and `K_w` is the depth-`n` cylinder image;
- `P^U(s) = limsup_n (1/n) log Z_n^U(s)`;
- `Z_n^L(s)` from the lower-pressure packaged family at depth `n`;
- `P^L(s) = limsup_n (1/n) log Z_n^L(s)`.

On the proved class, the bounded-overlap theoremlet yields a uniform constant `M < infinity` such that for every depth `n` and every `s >= 0`,
`Z_n^L(s) <= Z_n^U(s) <= M Z_n^L(s)`.
Hence `P^L(s) = P^U(s) =: P(s)`.
Let `s_*` be the unique zero of `P`. Then

`dim_H K = s_*`

where `P(s_*) = 0`.

## Proof route
1. Use T17 unchanged: if `P^U(s) < 0`, then `dim_H K <= s`.
2. Use T18 unchanged on the same lower-pressure core: if `P^L(s) > 0`, then `dim_H K >= s`.
3. Replace the old coincidence ingredient by S1-T2: bounded cylinder multiplicity plus exact cylinder packaging and equal-scale geometry imply
   `Z_n^L(s) <= Z_n^U(s) <= M Z_n^L(s)`.
4. Divide the logarithmic gap by depth, obtain `P^U(s)=P^L(s)`, and define the common pressure `P`.
5. Conclude Bowen formula exactly as in v1: `s > s_*` gives the upper bound, `s < s_*` gives the lower bound, hence `dim_H K = s_*`.

## Outside the proved class
Still outside the proved class are:
- stage-dependent / nonstationary admissibility families;
- families where lens or packaging feeds back into admissibility;
- local-domain families lacking equal-scale cylinders;
- local-domain families where overlap control cannot be reduced to bounded multiplicity from finitely many stationary continuation types.

In particular, the overlap patch does not yet rescue the non-SFT witness issue by itself: it enlarges the theorem cleanly, but the enlarged class remains prefix-memory / equal-scale in nature.
