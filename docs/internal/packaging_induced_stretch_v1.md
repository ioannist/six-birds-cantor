## Broadening criteria
A packaging route counts as a broader Level-3 target only if it is nondegenerate, uses P5 in a stronger theorem role than the working cocycle route, and supports a strictly broader class or shell than the closed cocycle route.

## Decision
`packaging_route_plausible_but_not_broader`

The packaging route is real and theorem-relevant, but it does not yet justify a broader class than the closed cocycle route.

## Why the rejected options are not the default now
`packaging_induced_wider_shell_class` is not supported as a genuinely broader theorem class by the current finite-horizon diagnostics. `cocycle_route_is_final_best_story` remains the default proof story for now because it is the closed, sharper route, even though packaging-induced pressure remains a useful reserve branch.

## What the next theorem ticket should try to prove
A packaging-induced theoremlet would need a genuinely broader or stronger shell-class result than the cocycle route, with P5 carrying theorem-relevant weight that is not merely observable-level.
