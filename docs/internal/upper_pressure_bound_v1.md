# Upper Pressure Bound v1

## Theorem target
For any family in the primary class `safe_finite_memory_local_subclass`, let `K` be the geometric attractor generated by its admissible branches, and let
`P^U(s) = limsup_{n->infty} (1/n) log Z_n^U(s)`
be the upper pressure built from admissible depth-`n` branches. The target upper-bound statement is:

> If `P^U(s) < 0`, then `H^s(K) = 0`. Hence `dim_H K <= s`.

Equivalently,
`dim_H K <= s^U := inf { s : P^U(s) < 0 }`.

## Notation
- `A_n`: admissible words / branches of length `n`.
- `w = i_1 ... i_n`: an admissible branch.
- `K_w`: cylinder image corresponding to `w`.
- `D_n = {K_w : w in A_n}`: depth-`n` cylinder covering family.
- `r_w`: nominal contraction product attached to branch `w`.
- `Z_n^U(s) = sum_{w in A_n} r_w^s`.
- `P_n^U(s) = (1/n) log Z_n^U(s)`.

## Geometric object vs observation layer
For the primary class, the geometric object is determined by branch maps, admissibility, and cylinder images. Lens and packaging are not part of the geometric object used for the upper bound. They may appear in diagnostics or lower-pressure bookkeeping, but they do not enter the covering argument for `dim_H K <= s`.

## Lemma 1: Cylinder covering lemma
**Claim.** For each depth `n`, the attractor `K` is covered by the depth-`n` admissible cylinder images:
`K subset union_{w in A_n} K_w`.

**Assumptions used.**
- `uniform_contraction`
- `finite_memory_bound`
- `stationary_admissibility_rule`
- `feedback_free_admissibility`

**Proof scaffold.**
1. Define `K_n` as the stage-`n` geometric approximation obtained by applying all admissible depth-`n` branches.
2. By construction, `K_{n+1} subset K_n` and `K subset K_n` for all `n`.
3. Each component of `K_n` is contained in a cylinder image `K_w` with `|w| = n`.
4. Therefore `K subset union_{w in A_n} K_w`.

## Lemma 2: Diameter/radius control lemma
**Claim.** There is a uniform constant `C >= 1` such that for every admissible branch `w`,
`diam(K_w) <= C r_w`.
In exact affine/similarity witnesses, one can take `C = 1` after normalization.

**Assumptions used.**
- `uniform_contraction`
- `bounded_distortion`

**Proof scaffold.**
1. In similarity/affine witnesses, the image diameter is exactly the product contraction times the seed diameter.
2. In the abstract primary class, bounded distortion upgrades nominal branch weights to actual diameter control up to `C`.
3. Hence each covering set `K_w` contributes at most `(C r_w)^s` to `s`-Hausdorff content.

## Lemma 3: Submultiplicative pressure estimate
**Claim.** The upper partition sums satisfy a finite-memory submultiplicative estimate:
`Z_{n+m}^U(s) <= C_s Z_n^U(s) Z_m^U(s)`
for a constant `C_s` depending only on the class data and `s`.

**Assumptions used.**
- `finite_memory_bound`
- `stationary_admissibility_rule`
- `feedback_free_admissibility`
- `uniform_contraction`
- `usable_separation`

**Proof scaffold.**
1. Finite memory implies admissible concatenations are controlled by a bounded set of terminal/initial contexts.
2. Stationarity and feedback-free admissibility prevent the context bookkeeping from changing with depth.
3. Summing over the bounded connecting-context ambiguity gives the constant `C_s`.
4. Therefore `P_n^U(s)` has the needed upper asymptotic control; in particular if `P^U(s) < 0`, then `Z_n^U(s)` decays exponentially along a subsequence or eventually.

**Localized gap.**
The exact statement of the bounded connecting-context constant for the full primary class still needs to be written cleanly for simple local-domain families, not just symbolic bounded-memory families.

## Lemma 4: Covering-to-dimension step
**Claim.** If `P^U(s) < 0`, then `H^s(K) = 0`.

**Assumptions used.**
- `uniform_contraction`
- `bounded_distortion`
- `finite_memory_bound`
- `stationary_admissibility_rule`
- `feedback_free_admissibility`

**Proof scaffold.**
1. Use Lemma 1 to cover `K` by `D_n`.
2. Use Lemma 2 to estimate the `s`-cost of that cover by
   `sum_{w in A_n} diam(K_w)^s <= C^s Z_n^U(s)`.
3. Use Lemma 3 plus `P^U(s) < 0` to conclude the right-hand side tends to `0` along the covering sequence.
4. Therefore the `s`-Hausdorff outer content of `K` is `0`, so `H^s(K) = 0` and `dim_H K <= s`.

## Dependency chain
- The theorem target depends on Lemma 1 + Lemma 2 + Lemma 3 + Lemma 4.
- Lemma 4 consumes the covering from Lemma 1, the diameter control from Lemma 2, and the pressure decay from Lemma 3.

## Where the proof would fail outside the primary class
- **Stage-dependent / nonstationary admissibility:** the finite-memory concatenation control in Lemma 3 breaks if the rule changes with stage.
- **Admissibility driven by runtime lens/packaging feedback:** the admissible branch set is no longer a fixed geometric object, so Lemma 1 and Lemma 3 stop being stable.
- **Poor overlap / packaging control:** if cylinder geometry is not controlled, Lemma 2 may fail or the cover cost may no longer be estimated by `Z_n^U(s)`.
- **Feedback families in current repo form:** `contextual_local.feedback_lens_protocol_coupled` is currently outside the primary class precisely because these failures are live risks, not hypothetical ones.
